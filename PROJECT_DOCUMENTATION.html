2. Client Roles & Responsibilities

All client surfaces act purely as control and monitoring interfaces. The recording lifecycle remains authoritative on the server and is decoupled from client connectivity.

Client Interface Core Responsibilities
Android Mobile App User login, meeting intake, job dispatching, live recording status HUD, ExoPlayer media playback, signed URL downloads.
Desktop App (Electron) Dashboard monitoring, quick intake, real-time waveform visualizers, media library management, settings configuration.
Telegram Control Plane Remote management commands (/record, /stop, /status, /recordings, /health), operator allowlist, automated status alerts.

3. Server RTMS Media Worker & FFmpeg Pipeline

3.1 Media Ingestion & Timestamp Synchronization

The worker consumes Zoom Realtime Media Streams (RTMS) via WebSocket connections. Monotonic timestamps are derived from incoming packet metadata to guarantee accurate audio/video synchronization.

3.2 State Machine Lifecycle

CREATED ──► QUEUED ──► STARTING ──► CONNECTING ──► CONNECTED ──► RECORDING
                                                                     │
                                                                     ▼
COMPLETED ◄── UPLOADING ◄── FINALIZING ◄── STOPPING ◄────────────────┘

3.3 FFmpeg Finalization

Muxes raw audio/video streams into seekable MP4 containers with -movflags +faststart, followed by container integrity and duration verification.

4. Security & Privacy Model

  • Official Authorization: Uses Zoom OAuth 2.0 and ZAK (Zoom Access Key) tokens.
  • Ephemeral Credentials: Meeting passcodes are maintained in worker memory only for active sessions and never persisted in plaintext.
  • Access Control: Media downloads are gated behind short-lived cryptographically signed URLs.

5. Experimental WebView Capture Research Module

Module Designation: experimental/webview-recorder/ is classified as an independent research module for in-app surface capture (PixelCopy) and Web Audio experiments. It is isolated from the core production pipeline.
